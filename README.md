# DSP Lab Android

A research-oriented Android prototype for interactive Digital Signal Processing experiments.

## Current version

**V0.1 – Lab 01**

Implemented:
- Kotlin + Jetpack Compose Android application
- Discrete-time sine, unit impulse, and unit step signals
- Interactive frequency, phase, and sample-count controls
- Time-domain stem-style visualization
- Minimal dependencies for reproducible educational research

## Planned labs

1. Discrete-Time Signals
2. Sampling and Aliasing
3. Discrete Convolution
4. DFT / FFT
5. FIR / IIR Filtering

## Research direction

The platform is designed as a lightweight experimental tool for studying parameter manipulation, visualization, reflection, and immediate feedback in DSP education.
